Pandas is a powerful python library used for data manipulation and analysis. It provides easy to used data structures and function to work with
structured data efficiently.  
**Benefits :**  
1. Easy Data Handling : Pandas makes it simple to load, clean and manipulate data.
2. It provides **dataframe** and **series** to store and organize data.
3. Handle missing values, duplicates and data formatting easily.
4. Perform filtering, sorting, grouping, and summarizing data with ease.
5. Pandas integrates smoothly with NumPy, Matplotlib and scikit-learn.
